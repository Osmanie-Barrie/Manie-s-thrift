MANIE'S THRIFT WEBSITE

Open index.html in a browser to view the responsive website.

Responsive layouts:
- Desktop/laptop: full navigation, two-column hero and story, three product cards.
- Tablet: condensed header and spacing.
- Phone: stacked hero/story, compact navigation, two-column product cards, stacked footer.

Before publishing:
1. Replace the sample fashion photos (images.unsplash.com URLs) with your own product and shop photos.
2. Update social profile links in the footer to your real accounts.
3. Add real product names, prices and stock information.
4. The email signup is a front-end demo; connect it to a mailing-list service if you want to collect emails.
5. WhatsApp ordering links use the business number supplied for Manie's Thrift.

The site is a single self-contained HTML file with embedded CSS and JavaScript. An internet connection is needed for the sample photos.
